# 沐橙（Morange）全产品系列矩阵
统一命名规则：全系列前缀固定为 **沐橙XX**，英文对应 **Morange XX**，品牌辨识度统一；按「纯前端快速上线→高留存核心产品→可拓展后端增值」分四梯队落地，前期零服务成本，后期加云同步、账号体系可无缝升级，不违和品牌定位。

---

## 一、家族中枢：总入口产品（必做，串联全系列）
### 沐橙工具箱（Morange Box）
- 核心定位：沐橙全系列工具的统一导航入口，所有子产品的分发中枢
- 核心功能：工具分类展示、一键跳转对应小程序、使用记录、收藏常用工具
- 品牌价值：把零散工具收拢成完整生态，用户用一个就能找到全部，形成导流闭环
- 后端拓展：后续可加账号登录、云端同步收藏、工具个性化推荐

---

## 二、第一梯队：极速上线款（1-2天/个，纯前端无后端，快速铺产品线）
纯计算/纯本地存储逻辑，开发成本极低，先上线占位、完善家族产品版图
1. **沐橙换算**（Morange Convert）
   - 核心功能：长度、重量、面积、体积、时间、进制、像素等常用单位换算
   - 实现方式：纯前端数学计算，无任何网络请求，离线完全可用
   - 后端拓展：后续可加实时汇率、实时金价等联网数据功能

2. **沐橙番茄**（Morange Focus）
   - 核心功能：25分钟标准番茄专注计时、休息提醒、本地统计每日专注时长、专注历史日历
   - 实现方式：前端定时器+本地缓存记录，无需后台
   - 后端拓展：后续可加专注数据云同步、专注排行榜、白噪音音频库

3. **沐橙随机**（Morange Random）
   - 核心功能：随机数字、抽签分组、骰子转盘、真心话大冒险题库、随机选择器
   - 实现方式：前端随机算法，题库内置在项目代码中
   - 后端拓展：后续可加自定义题库云端保存、多人联机抽签

---

## 三、第二梯队：高频留存款（2-3天/个，纯前端可用，用户粘性最高）
日常刚需工具，用户使用频率高、留存久，是沐橙品牌的核心主力产品
1. **沐橙记账**（Morange Bill）
   - 核心功能：收支录入、分类标签、日期筛选、月度收支统计、饼图/柱状图可视化
   - 实现方式：全部数据本地缓存存储，前端渲染统计图表
   - 后端拓展：后续可加多设备云同步、账单分类云端自定义、预算提醒、多账本

2. **沐橙纪念日**（Morange Days）
   - 核心功能：生日、节日、考试、旅行等自定义倒计时/正数日、分类管理、置顶重要日期
   - 实现方式：本地存储所有日期数据，前端计算天数差
   - 后端拓展：后续可加云端备份、日期提醒推送、年度日历视图

3. **沐橙便签**（Morange Note）
   - 核心功能：文本笔记、标签分类、置顶、关键词搜索、支持添加本地图片
   - 实现方式：笔记数据+图片临时路径全部本地缓存，纯前端增删改查
   - 后端拓展：后续可加云端同步、富文本编辑、笔记加密、多端编辑

4. **沐橙打卡**（Morange Habit）
   - 核心功能：自定义习惯、每日打卡、连续打卡天数统计、日历视图打卡记录
   - 实现方式：本地存储习惯与打卡记录，前端渲染打卡日历
   - 后端拓展：后续可加打卡云端备份、习惯打卡社群、数据趋势分析

---

## 四、第三梯队：深度价值款（3-5天/个，纯前端可用，后端拓展性极强）
有明确差异化价值，现在单机可用，未来加服务端后竞争力大幅提升
1. **沐橙词本**（Morange Word）
   - 核心功能：内置四六级/考研/日语等基础词库、单词背诵、生词本、记忆标记、复习提醒
   - 实现方式：词库内置在JS文件，背诵进度本地缓存
   - 后端拓展：后续可加云端词库、自定义生词本同步、背单词打卡排行、艾宾浩斯智能复习

2. **沐橙题库**（Morange Quiz）
   - 核心功能：分章节选择题/判断题刷题、错题本收藏、自动判分、刷题进度统计
   - 实现方式：题库数据写在本地文件，答题记录本地保存
   - 后端拓展：后续可加在线题库更新、模拟考试、错题云端同步、学习报告

3. **沐橙密码本**（Morange Key）
   - 核心功能：前端AES加密存储账号密码、分类管理、一键复制、搜索账号
   - 实现方式：加密后数据存本地缓存，解密仅在前端执行，全程不上传
   - 后端拓展：后续可加云端加密备份、多端同步、二次验证、密码强度检测

4. **沐橙健康**（Morange Health）
   - 核心功能：BMI计算、标准体重估算、基础代谢计算、健康建议文案
   - 实现方式：纯前端公式计算，静态健康建议文案
   - 后端拓展：后续可加体重记录趋势、健康数据云同步、饮食运动建议

---

## 五、第四梯队：创意拓展款（进阶能力，丰富产品线）
依托小程序Canvas能力，纯前端实现，打造差异化趣味工具
1. **沐橙作图**（Morange Design）
   - 核心功能：图片加文字、裁剪、滤镜、表情包制作、纯色壁纸生成
   - 实现方式：Canvas前端渲染处理，图片保存至本地相册
   - 后端拓展：后续可加模板云端库、素材中心、作品云端保存

2. **沐橙小游戏合集**（Morange Games）
   - 核心功能：2048、五子棋、井字棋、数字华容道等单机小游戏
   - 实现方式：纯前端Canvas逻辑，本地存储最高分记录
   - 后端拓展：后续可加全服排行榜、成就系统、对战匹配
