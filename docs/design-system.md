# 产品族视觉规范

## 设计目标

Morange 是一组轻量、日常、高频的小工具。视觉上必须保持“温暖、清爽、可靠、成体系”，所有产品都应像同一个品牌下的不同工具，而不是不同模板拼接。

## 品牌基调

- 中文品牌：沐橙。
- 英文品牌：Morange。
- 核心气质：温暖、轻巧、实用、有秩序。
- 视觉关键词：橙色、柔和渐变、圆角卡片、清晰信息层级、低噪声装饰。

## 色彩规范

品牌主色来自 `packages/constants` 的 `BRAND`。

```text
Morange Orange: #E66C32
Morange Orange Light: #F3A06F
Morange Orange Dark: #A9471F
Text Primary: #2a211b
Text Strong: #26160a
Text Secondary: #75675e
Background Warm: #fff4e7 -> #fffaf4 -> #f7f4ee
Card White: rgba(255, 255, 255, 0.82)
Border Warm: rgba(119, 72, 29, 0.08)
Shadow Warm: rgba(90, 52, 12, 0.08)
```

使用规则：

- 主按钮、关键数据、导航高亮使用品牌橙。
- 页面背景使用暖色渐变或浅暖灰，不使用纯白平铺。
- 每个小程序允许有一个 `accent` 辅助色，用于图标底、标签或详情页头图，不允许大面积替代品牌橙。
- 成功、警告、错误状态可以使用语义色，但必须降低饱和度，避免破坏产品族统一。

## 字体与排版

- 中文字体栈：`'PingFang SC', 'Hiragino Sans GB', sans-serif`。
- 标题使用高字重：`800` 或 `900`。
- 正文使用 `24px` 到 `28px`，行高 `1.5` 到 `1.65`。
- 数据和核心标题可以放大，但必须服务信息层级，不做无意义大字。

推荐层级：

```text
Hero Title: 46px - 56px / 900
Section Title: 32px - 36px / 900
Card Title: 30px - 34px / 800
Body: 24px - 28px / 400-600
Caption/Tag: 20px - 22px / 600-800
```

## 间距与圆角

- 页面边距：`28px`。
- 卡片内边距：`24px` 到 `36px`。
- 模块间距：`26px` 到 `36px`。
- 小元素间距：`10px` 到 `18px`。
- 卡片圆角：`26px` 到 `34px`。
- Hero 圆角：`40px` 到 `44px`。
- 标签和按钮胶囊：`999px`。

## 页面结构

普通工具类小程序建议使用统一结构：

```text
Page
  Hero：产品名、说明、核心状态或入口
  Primary Action：主功能操作区
  Content Cards：结果、历史、列表、设置
  Secondary Area：说明、快捷入口、关联产品
```

工具箱类中枢页面建议使用：

```text
Hero：品牌和产品族定位
Metrics：产品数量、收藏、最近使用等概览
Featured：优先上线或高频工具
Personal：收藏和最近使用
Matrix：按梯队/分类展示产品族
```

## 组件统一

### 卡片

- 背景使用半透明白色。
- 必须有圆角和轻阴影。
- 内容层级固定为：图标、标题、状态、摘要、标签、操作。
- 同类卡片在不同小程序中不得改变核心结构。

### 按钮

- 主按钮：品牌橙底、白字、粗体。
- 次按钮：浅橙底、深橙字。
- 危险操作：仅在删除或清空数据时使用红色，且必须二次确认。

### 标签

- 默认浅橙背景、深橙文字。
- 状态标签统一文案：`已接入`、`搭建中`、`规划中`。
- 标签数量默认不超过 3 个，详情页可以展示更多。

### 图标

- 图标必须来自同一视觉系列。
- App 内资源统一放在 `src/assets/icons`。
- 工具箱展示图标尺寸：卡片 `68px`，快捷入口 `58px`，详情页 `132px`。
- 新增图标必须同时保留原始资源到根目录 `icon/`。

## 动效规范

- 小程序端动效保持克制，优先使用页面自然滚动和状态反馈。
- 可使用轻微进入、按压、展开动画，但不得影响操作效率。
- 计时、转盘、抽签等工具可以有业务相关动效，但要避免持续高频动画造成耗电。

## 统一性检查

新增页面合并前必须检查：

- 是否使用品牌橙作为主视觉锚点。
- 页面背景是否保持暖色体系。
- 卡片圆角、阴影、间距是否接近现有工具箱。
- 标题、正文、标签字号是否符合层级。
- 小程序 `accent` 是否只作为点缀。
- 是否复用了 `packages/ui` 中已有组件。

## 禁止项

- 禁止每个小程序独立使用完全不同的颜色体系。
- 禁止纯白背景加默认蓝色按钮的系统模板风格。
- 禁止大面积紫色、黑色或高饱和霓虹色作为主视觉。
- 禁止把 `accent` 当品牌色使用。
- 禁止页面内出现多个互相竞争的主按钮。
