# 沐橙开发规范

本目录是 Morange 产品族的工程与设计约束。新增小程序、组件、页面、样式前必须先对照这些规范。

## 文档索引

- [工程开发规范](./development-standards.md)：仓库结构、命名、编码、数据、质量门禁。
- [产品族视觉规范](./design-system.md)：品牌基调、色彩、排版、间距、组件统一规则。
- [新增小程序清单](./mini-program-checklist.md)：从立项到接入工具箱的落地步骤。

## 核心原则

- 产品族统一：所有小程序必须看起来属于“沐橙”体系，而不是独立外包页面。
- 共享优先：跨小程序复用内容进入 `packages/*`，不要复制粘贴到每个 `apps/*`。
- 本地优先：第一阶段默认纯前端和本地存储，除非产品定义明确需要后端。
- 可验证：每次交付至少通过 `pnpm type-check` 和目标小程序 `build`。
