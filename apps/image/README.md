# 沐橙图片小程序

本地处理图片，保护隐私，不上传服务器。

## 功能列表

### 1. 9宫格切图 ⚡️
将一张图片切分为多个小图，适合制作朋友圈九宫格。

**功能特性：**
- 支持 2×2（4张）、3×3（9张）、4×4（16张）切图
- 实时预览切图网格
- 批量保存到相册

### 2. 长图拼接 🔗
将多张图片拼接成一张长图。

**功能特性：**
- 支持最多 9 张图片
- 横向/纵向拼接
- 自定义图片间距（0-50px）
- 自动居中对齐

### 3. 图片压缩 📦
压缩图片大小，减少存储空间。

**功能特性：**
- 三档质量选择（高/中/低）
- 目标大小限制（200KB/500KB/1MB/不限）
- 显示压缩率
- 智能二分查找最优压缩质量

### 4. 尺寸修改 📏
调整图片尺寸，适配不同场景。

**功能特性：**
- 预设尺寸（头像、封面、朋友圈、竖屏）
- 自定义尺寸
- 保持比例/自由调整
- 自动降采样超大图片

### 5. 图片水印 💧
为图片添加文字或平铺水印。

**功能特性：**
- 单个水印/平铺水印
- 自定义文字内容
- 调整字号大小（20-120px）
- 5种颜色选择
- 透明度调节（10%-100%）
- 9宫格位置选择

### 6. 格式转换 🔄
转换图片格式，满足不同需求。

**功能特性：**
- 支持 JPG、PNG、WebP 互转
- 格式说明和适用场景提示
- 保持原始尺寸

## 技术特性

### 性能优化
- **内存管理**：使用完立即销毁 Canvas，及时清空引用
- **大图处理**：自动降采样超过 4096px 的图片
- **批量处理**：异步队列处理多图任务
- **防抖节流**：优化用户操作响应

### 安全特性
- **本地处理**：所有图片在本地 Canvas 处理，不上传服务器
- **隐私保护**：处理完成后自动清理临时文件
- **权限管理**：仅在保存时请求相册权限

### 用户体验
- **实时预览**：所有操作支持实时预览效果
- **友好提示**：清晰的操作引导和错误提示
- **加载状态**：处理过程显示 loading 状态
- **沐橙橙色主题**：统一的品牌视觉

## 技术栈

- **框架**：Taro 4.2.0 + React 18
- **语言**：TypeScript
- **样式**：SCSS
- **构建**：Webpack 5
- **图片处理**：Canvas 2D API

## 注意事项

1. **Canvas 限制**：微信小程序 Canvas 最大尺寸为 4096×4096，超大图会自动降采样
2. **内存占用**：处理大图或多图拼接时可能占用较多内存，建议一次处理不超过 9 张图
3. **格式兼容**：WebP 格式在部分老设备可能不支持
4. **相册权限**：首次保存需要用户授权相册权限
