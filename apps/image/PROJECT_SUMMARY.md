### 2. 9宫格切图

- 三档质量（高/中/低）
- 目标大小限制（200KB/500KB/1MB）
- 智能二分查找最优质量
- 实时显示压缩率

### 5. 尺寸修改
- 预设尺寸（头像/封面/朋友圈/竖屏）
- 自定义尺寸输入
- 保持比例/自由调整
- 实时计算尺寸

### 6. 图片水印
- 单个水印/平铺水印
- 文字内容自定义
- 字号调整（20-120px）
- 5 种颜色选择
- 透明度调节（10%-100%）
- 9 宫格位置选择

### 7. 格式转换
- JPG/PNG/WebP 互转
- 格式说明提示
- 保持原始质量

## 🏗️ 技术架构

### 核心工具库

```
lib/
├── canvas-helper.ts       # Canvas 通用操作（181 行）
│   ├── queryCanvas()      # 查询 Canvas 节点
│   ├── loadCanvasImage()  # 加载图片
│   ├── exportCanvas()     # 导出为临时文件
│   ├── getFileSize()      # 获取文件大小
│   ├── getScaledSize()    # 自动降采样
│   └── saveToAlbum()      # 保存到相册
│
├── image-processor.ts     # 图片处理核心（107 行）
│   ├── compressImage()    # 图片压缩（支持目标大小）
│   ├── resizeImage()      # 尺寸修改
│   └── convertFormat()    # 格式转换
│
├── split-grid.ts          # 切图算法（48 行）
│   └── splitImage()       # 9宫格切图
│
├── merge-images.ts        # 拼接算法（88 行）
│   └── mergeImages()      # 多图拼接
│
└── watermark.ts           # 水印绘制（175 行）
    ├── addWatermark()     # 添加水印入口
    ├── drawTextWatermark()   # 文字水印
    ├── drawImageWatermark()  # 图片水印
    └── drawTileWatermark()   # 平铺水印
```

### 性能优化策略

1. **内存管理**
   - Canvas 使用完立即销毁
   - 图片处理完清空引用
   - 临时文件自动清理

2. **大图处理**
   - 超过 4096px 自动降采样
   - 分块渲染避免内存溢出
   - MAX_CANVAS_SIZE 常量限制

3. **压缩优化**
   - 二分查找最优质量（最多 8 次迭代）
   - 避免多次无效压缩
   - 智能质量区间调整

4. **批量处理**
   - 异步队列处理多图
   - 显示处理进度
   - 错误容错机制
